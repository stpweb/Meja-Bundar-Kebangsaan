## Apa Ini?

**Meja Bundar Kebangsaan** adalah sebuah *skill* AI — sebuah berkas instruksi yang dapat dimuat ke dalam model bahasa besar (LLM) untuk mengubahnya menjadi ruang deliberasi intelektual kebangsaan. Skill ini bukan sekadar chatbot bertema sejarah. Ia adalah **mesin analisis kebijakan** yang menghidupkan kembali semangat para pendiri bangsa, intelektual besar Indonesia, dan kerangka analisis geopolitik-geoekonomi kelas dunia untuk menjawab tantangan nyata Indonesia sepanjang horizon 2026 hingga 2076.

Ketika skill ini aktif, AI Anda berubah menjadi forum diskusi yang dipimpin oleh **Gus Dur** dan **Habibie**, diisi oleh 35+ tokoh nasional, dan dilengkapi dengan 11 modul analisis strategis. Ia dirancang untuk berpikir dari *first principles*, mengungkap struktur tersembunyi di balik masalah kompleks, dan memberikan rekomendasi kebijakan konkret yang berakar pada nilai-nilai Indonesia.

## Struktur File

Skill ini terdiri dari empat berkas utama yang saling melengkapi.

`SKILL.md` adalah instruksi utama yang mengonfigurasi perilaku AI: identitas forum, prinsip operasional, protokol pemilihan mode, alur *chain-of-thought*, dan semua perintah sistem. `references/tokoh.md` adalah ensiklopedia lengkap 35+ tokoh dengan profil pemikiran, gaya diskusi, dan relevansi kontemporer masing-masing. `references/analisis.md` memuat 11 Modul Analisis Geopolitik-Geoekonomi termasuk RIA OECD, Systems Thinking, dan Cascade Shock Modeling. `references/horizon.md` adalah peta tantangan dan peluang Indonesia per horizon waktu: 2026–2035 (puncak bonus demografi), 2035–2045 (transisi Indonesia Emas), dan 2045–2076 (pasca-bonus demografi dan masyarakat menua).

## Cara Penggunaan: Perintah Sistem

Setelah skill dimuat, gunakan perintah berikut untuk mengarahkan diskusi.

`/bundar:intake` — Memulai sesi dengan mengumpulkan konteks: topik, horizon waktu, sektor, tokoh yang difokuskan, dan level kedalaman yang diinginkan.

`/bundar:skenario <topik>` — Menjalankan simulasi diskusi penuh Meja Bundar dengan format standar: pembukaan Gus Dur, framing Habibie, pandangan multi-tokoh, kearifan lokal, edge cases, implikasi kebijakan, dan pertanyaan reflektif penutup.

`/bundar:challenge <rencana>` — Menjalankan *adversarial pre-mortem* kebangsaan: mengekstraksi asumsi inti sebuah kebijakan, menilai kerentanannya, memetakan rantai ketergantungan, dan mengidentifikasi *kill switches*.

`/bundar:war-room <skenario>` — Geopolitical War Room dengan pemodelan kaskade: mensimulasikan dampak bertingkat dari dua hingga tiga variabel krisis secara bersamaan, dari *base* hingga *severe*.

`/bundar:tokoh <nama>` — Menampilkan profil mendalam seorang tokoh: identitas historis, pemikiran inti, gaya intelektual, perspektif terhadap isu kontemporer, dan ketegangan yang perlu dikritisi.

`/bundar:profil <nama atau organisasi>` — Menghasilkan profil profesional standar publikasi Indonesia, dengan pilihan panjang: Singkat (150–250 kata), Standar (400–700 kata), atau Panjang (800–1500+ kata).

## Instalasi

### Claude (Anthropic)

### Sebagai Claude Skill
1. Unduh file `meja-bundar-kebangsaan.skill` dari repository ini
2. Buka Claude (claude.ai) di browser atau aplikasi
3. Masuk ke **Settings** > **Skills** > **Install from file**
4. Unggah file `meja-bundar-kebangsaan.skill`
5. Skill aktif dan siap digunakan di semua percakapan baru

### Sebagai Claude Projects
Buka pengaturan *Projects*, buat atau buka sebuah Project, lalu unggah berkas `meja-bundar-kebangsaan.skill` ke dalam Project tersebut. Claude akan membaca dan memuat instruksi secara otomatis. Alternatifnya, salin seluruh isi `SKILL.md` beserta ketiga berkas referensi dan tempelkan sebagai *system prompt* di awal percakapan baru.

Untuk penggunaan via API Anthropic, muat isi `SKILL.md` ke dalam parameter `system`, lalu sertakan ketiga berkas referensi sebagai dokumen tambahan dalam pesan pertama `user` dengan label yang jelas.

```python
import anthropic

with open("SKILL.md") as f:
    system_prompt = f.read()

# Sertakan referensi sebagai konteks awal
with open("references/tokoh.md") as f:
    tokoh = f.read()

client = anthropic.Anthropic()
response = client.messages.create(
    model="claude-opus-4-5",
    max_tokens=4096,
    system=system_prompt,
    messages=[
        {
            "role": "user",
            "content": f"[REFERENSI TOKOH]\n{tokoh}\n\n/bundar:skenario Tata kelola AI di Indonesia 2030"
        }
    ]
)
```

### Kimi (Moonshot AI)

Buka [kimi.moonshot.cn](https://kimi.moonshot.cn) atau aplikasi Kimi, lalu buat percakapan baru. Di menu pengaturan percakapan atau fitur *Custom Instructions*, tempelkan isi `SKILL.md` sebagai instruksi sistem. Kemudian kirim ketiga berkas referensi sebagai lampiran berkas di awal percakapan dan minta Kimi membacanya sebelum memulai diskusi. Kimi mendukung konteks panjang (hingga 128K token) sehingga dapat memuat keseluruhan skill sekaligus.

```
[Tempelkan isi SKILL.md di System Prompt / Custom Instructions]

[Unggah tokoh.md, analisis.md, horizon.md sebagai lampiran]

Kimi, tolong baca semua berkas referensi yang saya lampirkan, 
lalu konfirmasi bahwa Meja Bundar Kebangsaan sudah siap.
Setelah itu kita mulai dengan:
/bundar:skenario Kedaulatan data Indonesia di era big tech 2030
```

### Manus

Di Manus, buat *Agent* baru atau buka pengaturan Agent yang ada. Masukkan isi `SKILL.md` ke dalam kolom *System Prompt* atau *Agent Instructions*. Unggah ketiga berkas referensi (`tokoh.md`, `analisis.md`, `horizon.md`) ke dalam *Knowledge Base* Agent tersebut, lalu aktifkan fitur *File Reading* agar Agent dapat mengaksesnya saat berdiskusi. Simpan konfigurasi dan mulai sesi baru.

```
[System Prompt Agent: isi SKILL.md]

[Knowledge Base: tokoh.md | analisis.md | horizon.md]

Pesan pertama untuk memulai:
Halo Meja Bundar. Saya ingin memulai sesi dengan /bundar:intake
```

### Minimax (MiniMax AI)

Akses Minimax melalui antarmuka web atau API-nya. Untuk penggunaan via API, gunakan parameter `system_prompt` untuk memuat `SKILL.md`. Untuk antarmuka web, gunakan fitur *Bot Configuration* atau *Persona* yang tersedia, tempelkan instruksi di sana, dan lampirkan berkas referensi sebagai dokumen yang dapat dibaca oleh model.

```python
import requests

with open("SKILL.md") as f:
    system = f.read()

payload = {
    "model": "abab6.5s-chat",
    "messages": [
        {"role": "system", "content": system},
        {
            "role": "user", 
            "content": "/bundar:skenario Bonus demografi Indonesia dan risiko middle-income trap"
        }
    ],
    "max_tokens": 4096
}

response = requests.post(
    "https://api.minimax.chat/v1/text/chatcompletion_v2",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json=payload
)
```

### QWEN (Alibaba Cloud)

Gunakan [Tongyi Qianwen](https://qianwen.aliyun.com) via antarmuka web atau API Alibaba Cloud DashScope. Di antarmuka web, buka menu *System Prompt* atau *Assistant Configuration* dan tempelkan isi `SKILL.md`. Unggah berkas referensi sebagai dokumen di awal sesi. Via API DashScope:

```python
from dashscope import Generation

with open("SKILL.md") as f:
    system_prompt = f.read()

with open("references/tokoh.md") as f:
    tokoh_ref = f.read()

messages = [
    {"role": "system", "content": system_prompt},
    {
        "role": "user",
        "content": f"Referensi tokoh:\n{tokoh_ref}\n\n/bundar:skenario Geopolitik Laut China Selatan dan posisi Indonesia 2035"
    }
]

response = Generation.call(
    model="qwen-max",
    messages=messages,
    max_tokens=4096
)
```

### AI Lain yang Mendukung System Prompt

Untuk model lain yang mendukung konfigurasi *system prompt* (misalnya GPT-4, Gemini, Mistral, LLaMA yang di-*fine-tune*, dan lainnya), prosedur umumnya adalah: muat isi `SKILL.md` sebagai *system prompt* atau instruksi awal, kirimkan tiga berkas referensi sebagai konteks tambahan di pesan pertama pengguna, dan mulai percakapan dengan salah satu perintah `/bundar:*`. Skill ini dirancang agnostik terhadap model dan akan berfungsi optimal pada model dengan kapasitas konteks minimal 32K token.

**Catatan penting untuk semua platform:** Muat berkas referensi (`tokoh.md`, `analisis.md`, `horizon.md`) di awal sesi, sebelum pertanyaan substantif pertama. Ini memastikan AI memiliki basis pengetahuan lengkap sebelum memulai simulasi.

## Prinsip Desain

Skill ini dibangun di atas delapan prinsip operasional yang selalu aktif, terlepas dari mode atau perintah yang dipilih.

Pertama, **berpikir dari First Principles** — menghindari asumsi dan konvensi untuk menemukan kebenaran yang mendasar. Kedua, **mengungkap struktur tersembunyi** — mengidentifikasi *root causes*, *causal loops*, dan pola sistemik yang tidak kasat mata. Ketiga, **menghidupkan suara para tokoh** dengan akurasi spirit, bukan mengarang kutipan. Keempat, **mengintegrasikan kearifan Nusantara** — Gotong Royong, Sasi, Subak, Tepa Salira, Musyawarah Mufakat, Tri Hita Karana, dan Pela Gandong. Kelima, **mengidentifikasi bias kognitif** dalam setiap argumen. Keenam, **berorientasi pada tiga horizon waktu** yang eksplisit. Ketujuh, **menerapkan risk-tagging** pada setiap klaim: 🟢 VERIFIED / 🟡 MEDIUM / 🔴 ASSUMED. Kedelapan, **mengakhiri dengan pertanyaan reflektif** yang membuka diskusi lebih dalam.
